# Learning AI

A collection of small Python projects I'm building as I learn artificial intelligence, genetic algorithms, and evolutionary computing.

I'm currently following Daniel Shiffman's *The Nature of Code* to better understand how these algorithms work through hands-on projects.

## Projects

### 1. String Evolution
A genetic algorithm that evolves a population of random strings toward a target phrase.

**Concepts:** Fitness evaluation, selection, crossover, mutation, and reproduction.

### 2. Smart Rockets
A simulation exploring how rockets can learn to navigate toward a target using genetic algorithms.

**Concepts:** Vector-based movement, physics simulation, and evolutionary algorithms.

## Technologies
- Python
- NumPy
- Pygame / Pygame-CE

## Getting Started

Clone the repository:

```bash
git clone https://github.com/NguyenThomas986/Learning_AI.git
cd Learning_AI
```

Run the string evolution project:

```bash
python string_evolution.py
```
